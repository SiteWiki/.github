## About SiteWiki

**SiteWiki** is an open-source knowledge collection dedicated to discovering and organizing valuable resources across the web.

We believe useful information should be easy to discover, well-organized, and accessible to everyone.

Our goal is to build a structured knowledge base covering websites, SEO resources, online tools, technical documentation, and digital resources.

Rather than simply bookmarking links, we aim to provide meaningful descriptions, categorized collections, and practical documentation to help people find the right resources.

## What We Collect

| Category | Description |
|---|---|
| 🌐 Websites | Useful websites, directories, and online resources |
| 🔍 SEO Resources | SEO tools, blogs, guides, and optimization resources |
| 🛠️ Online Tools | Productivity tools, web utilities, and developer tools |
| 📚 Learning Resources | Tutorials, documentation, courses, and knowledge bases |
| 🤖 AI Resources | AI tools, platforms, and related resources |
| 💻 Developer Resources | APIs, libraries, frameworks, and technical references |
| 📈 Growth & Marketing | Digital marketing, organic growth, and analytics |

## Our Principles

- **Curated:** Focus on useful and valuable resources.
- **Organized:** Keep information structured and easy to navigate.
- **Open:** Make knowledge accessible to the community.
- **Practical:** Provide descriptions and context, not just links.
- **Collaborative:** Welcome contributions and suggestions.

## How to Contribute

We welcome contributions from everyone!

You can help SiteWiki grow by:

1. Discovering and submitting useful websites and tools.
2. Improving existing documentation and descriptions.
3. Adding new categories and organizing resources.
4. Reporting outdated or broken links.
5. Sharing SEO knowledge, tutorials, and practical experiences.

If you have a useful resource to share, feel free to open an issue or submit a pull request to the relevant repository.

## Community & Feedback

Have a suggestion or found something interesting?

- Browse our [Repositories](https://github.com/orgs/SiteWiki/repositories).
- Report issues and suggest resources through GitHub Issues.
- Contribute improvements through Pull Requests.
